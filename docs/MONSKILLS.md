# MONSKILLS — team setup

Official agent skills for building on Monad. Install locally, then tell your agent to use them. Prefer local skills over fetching the website during the build.

## Install (every teammate, once per machine / clone)

From the **repo root**:

```bash
npx skills add therealharpaljadeja/monskills
```

That copies skills into agent folders (e.g. `.agents/skills/`) and writes/updates `skills-lock.json` (pinned hashes — commit this file).

### Claude Code (optional)

```text
/plugin marketplace add therealharpaljadeja/monskills
/plugin install monskills@monskills
```

## After install — tell your agent

Paste this (or point them at this file):

```text
Use the locally installed MONSKILLS. Start with the monskill routing skill, then fetch only the local topic skills needed for the task.
```

**Agent rule:** always start with local `monskill`, then only the topic skills that router lists. Use the website only if local install is missing.

## Local entry point

| Skill | Path (after install) | Role |
|---|---|---|
| **monskill** | `.agents/skills/monskill/SKILL.md` | Router — start here |
| scaffold | `.agents/skills/scaffold/` | Idea → production |
| wallet-integration | `.agents/skills/wallet-integration/` | Frontend wallets / Para |
| addresses | `.agents/skills/addresses/` | Canonical addresses (never invent) |
| gas | `.agents/skills/gas/` | Gas limit pricing on Monad |
| concepts | `.agents/skills/concepts/` | Async execution, block states, etc. |
| tooling-and-infra | `.agents/skills/tooling-and-infra/` | RPC, explorers, indexers |
| indexer | `.agents/skills/indexer/` | Event indexing (Envio, etc.) |
| why-monad | `.agents/skills/why-monad/` | Why Monad |

Note: the upstream `wallet` skill (Alchemy agent wallet) may be skipped by the installer if its YAML is broken. Use `wallet-integration` for frontend wallets; deploy via Foundry / docs as usual.
