## Blitz submission process (organiser)

1. Visit the [`monad-blitz-london`](https://github.com/monad-developers/monad-blitz-london) repo and fork it (already done for this repo).
2. Build in this fork; update this README with project name, one-liner, and demo links.
3. Deploy to **Monad Testnet**, keep the repo public.
4. Submit on the [Blitz Portal](https://blitz.devnads.com).

See organiser screenshots under [`screenshots/`](screenshots/) and details in [`docs/event_details/`](docs/event_details/).
